## Keputusan yang diambil sendiri

1. **Branch dari `fix/t-006-web-auth-emulator`, bukan `master`.** Entri T-007 di `docs/TASKS.md` baru ada di branch T-006 (belum di-merge), jadi branch dari `master` tidak punya entri yang bisa dicentang. Akibatnya branch ini memuat commit T-006; merge T-006 lebih dulu, atau merge branch ini saja bila T-006 sudah diterima.
2. **Dicatat di batas (`apiCall`, repository), bukan di mapper atau konstruktor `Failure`.** `Failure` dipakai domain (Dart murni), dan mapper tetap fungsi murni yang diuji tanpa efek samping. Kedua batas itu adalah satu-satunya tempat `Failure` dibuat dari exception (`grep "Failure("`).
3. **`debugPrint` + `kDebugMode`, bukan package logging.** Tanpa dependency baru; `debugPrint` tampil di konsol `flutter run` dan DevTools. Parameter `debug` membuat perilaku mode rilis bisa diuji.
4. **Isi log**: kode, `Failure.message`, dan nama field yang gagal validasi (bukan isi `FieldIssue`). Tidak ada token atau header; pesan Firebase dan API saat ini tidak memuat email atau token. Hanya di mode debug.
5. **Output test lebih ramai**: test yang melewati `apiCall` atau repository auth dengan error kini mencetak satu baris `Failure …` di output `flutter test` (test berjalan dalam mode debug). Dibiarkan, karena memang perilaku yang diinginkan.
6. **Rujukan sisa notes di konvensi diperbaiki**: contoh kunci `fieldErrors` di bagian "Result dan Failure" masih `title` (dari notes), diganti `name`.
