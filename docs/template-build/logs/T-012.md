## Keputusan yang diambil sendiri

- **Format: sesuai instruksi user.** File Dart hasil generate tidak diformat ulang dan `contract:check` membandingkannya apa adanya; `openapi.json` diformat Biome setelah export (seperti spike T-003). Ini menjawab catatan 4 dan 6 di log T-003.
- **Biome lewat stdin, di dalam `export-openapi.ts`.** File yang ditulis export sudah final, dan `contract:check` bisa menulis ke folder sementara di luar repo tanpa kehilangan konfigurasi `biome.json`.
- **`contract:check` generate ulang di salinan sementara**, bukan di tempat lalu dibandingkan dengan git. Working tree tidak berubah dan perbandingannya terhadap isi file saat ini (termasuk perubahan yang belum di-commit). `.dart_tool` ikut disalin agar builder tidak dikompilasi ulang (6 detik vs 44 detik).
- **`lib/src/api/` dihapus sebelum swagger_parser**, agar skema yang dihapus dari route tidak meninggalkan file usang; `contract:check` juga melaporkan file yang tidak lagi dihasilkan.
- **Yang dibandingkan hanya keluaran generator** (`openapi.json` dan `dart/lib/src/api/**`); file yang ditulis tangan di package tidak ikut.
- **`dart analyze` hanya di `generate`.** `check` cukup membuktikan kesamaan dengan hasil yang sudah lolos analyze saat di-generate; `pnpm check` (T-017) tetap menjalankan analyze untuk app.
- **`pubspec.lock` package Dart di-commit** (seperti spike), karena versi transitif generator (misalnya `dart_style` yang dipakai retrofit_generator) memengaruhi isi file hasil generate.
- **`info` OpenAPI `{ title: 'API', version: '1' }`**, generik agar tidak perlu diubah `init-project`.
- **`--delete-conflicting-outputs` tidak dipakai**: build_runner 2.16.1 memberi peringatan bahwa opsi itu sudah dihapus dan diabaikan.
- **Test Dart di package `api_client`** memakai JSON inline, bukan fixture dari respons nyata seperti spike: route notes butuh login dan database, sedangkan export sengaja tidak butuh keduanya. Kecocokan bentuk respons nyata dengan skema sudah dijaga test route API.

Usulan untuk `docs/conventions.md`: sudah ditambahkan (lihat Ringkasan).
