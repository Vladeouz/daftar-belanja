  - Bagian baru: "Struktur repo" (pohon folder root + paket workspace, D-09), "Prasyarat lingkungan" (`scripts/prereq.mjs`), "`pnpm check` dan CI" (usulan T-017 dan T-018), "Layanan lokal" (usulan T-002), "TypeScript" (PRD bagian 3: `strict`, `NodeNext`, import `.js`; contoh `apps/api/tsconfig.json`), "Image produksi API" (usulan T-019), "Organisasi dan tenancy" (D-11: PRD menyatakan polanya dijelaskan di `conventions.md`, sebelumnya belum ada), "Menghapus fitur contoh notes".

  - "Test API": timeout per test untuk `spawnSync` (usulan T-005), `current_database()` untuk `pg_stat_activity` (usulan T-017), tanpa retry untuk test flaky.
  - "Flutter": arah dependency dan larangan import di `domain` dinyatakan eksplisit (PRD bagian 3); dicek dengan `grep` bahwa `lib/features/*/domain` hanya mengimpor `package:app/` dan `equatable`.
  - Tabel versi sudah lengkap: dicocokkan dengan `package.json` root, `apps/api/package.json`, `apps/app/pubspec.yaml`, dan `packages/contract/dart/pubspec.yaml`; tidak ada yang terlewat (`flutter_localizations` adalah SDK).
- **PRD, TASKS, dan log** dipindah dengan `git mv` ke `docs/template-build/` (`PRD.md`, `TASKS.md`, `logs/`). Isinya tidak diubah; rujukan `docs/logs/...` di dalamnya dibiarkan sebagai catatan sejarah.
- **`spikes/`**: 63 file yang dilacak Git dihapus dengan `git rm -r`. Tidak ada rujukan ke `spikes` di file lain (`git grep`).
- **`CLAUDE.md`**: bagian "Dokumen" baru (peran `docs/conventions.md`, `docs/template-build/`, dan aturan peralihan: bila `docs/TASKS.md` belum ada, task diambil dari `docs/template-build/TASKS.md`), `conventions.md` tidak lagi "jika sudah ada", `pnpm check` wajib tanpa catatan T-017, rujukan "bagian 8 PRD" menjadi "bagian Assumptions & Decisions PRD" (nomor bagian di PRD proyek bisa berbeda), bagian "Fitur contoh". Bagian "Rujukan" ke repo `gym-membership` dihapus (khusus pembangunan template; tetap tercatat di D-13 dan log).

## Keputusan yang diambil sendiri

- **Log T-020 dan centang ditulis di `docs/template-build/`**, karena PRD/TASKS/log sudah dipindah di task ini. `CLAUDE.md` mendapat aturan peralihan agar sesi T-021 menemukan task-nya di sana; setelah `pnpm init-project` membuat `docs/TASKS.md` placeholder, aturan itu tidak berlaku lagi tanpa perlu diubah.
- **Script root `dev` tidak ditambahkan** (usulan T-017 yang diminta diputuskan di T-020). `conventions.md` menetapkan `pnpm --filter <paket> <script>` dan "tidak ada script root `dev`". PRD template tidak diubah (pohon foldernya masih menyebut `dev`); bila user ingin, pohon PRD bisa dikoreksi atau script `dev` ditambahkan di task lain.
- **Pola tenancy ditulis sebagai panduan tanpa kode**: tabel `organizations` + `memberships` dengan `role` `text` + CHECK, path `/v1/organizations/{organizationId}/...`, bukan anggota → `404` (konsisten dengan D-07), peran kurang → `403 FORBIDDEN` (sesuai peran `FORBIDDEN` di PRD bagian 5), pemeriksaan peran di use case. Ini pilihan paling sederhana yang konsisten dengan konvensi yang ada; proyek pertama yang memakainya diminta mencatat file contohnya.
- **Langkah "Menghapus fitur contoh notes"** ditambahkan (daftar file dari `git grep -i note`), karena PRD menyebut notes "ditiru lalu dihapus" tetapi belum ada panduan menghapusnya. Disarankan dihapus setelah fitur proyek pertama berdiri, agar agent tetap punya contoh untuk ditiru.
- **PRD dan TASKS tidak diubah isinya** saat dipindah, agar riwayat tetap utuh.

## Kendala

- **Hapus folder `spikes/` di disk ditolak pengaman mode otomatis** (dianggap penghapusan lokal yang tidak bisa dibatalkan). Semua file yang dilacak Git sudah dihapus lewat `git rm`, tetapi folder di disk masih berisi artefak yang di-ignore (`spikes/contract/api/node_modules/`, `.dart_tool/`, `build/`, `android/.gradle/`, dan sejenisnya). Setelah `.gitignore` milik spike ikut terhapus, sebagian artefak itu (file `.gradle`, `gradlew`, `gradle-wrapper.jar`) muncul sebagai untracked. User menghapus folder itu sendiri; setelahnya working tree bersih.
