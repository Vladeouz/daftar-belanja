## Keputusan yang diambil sendiri

- **Branch dari `feat/t-012-contract-pipeline`, bukan `master`.** T-012 belum di-merge ke `master`, sedangkan T-013 bergantung padanya (`packages/contract/dart`). Branch ini bertumpuk di atas T-012; merge T-012 dulu, lalu T-013.
- **Platform web, Android, iOS.** PRD menyebut ketiganya; folder `ios/` disertakan tetapi tidak bisa di-build atau diverifikasi di Windows.
- **Package Dart bernama `app`** (import `package:app/...`), mengikuti nama folder.
- **`FailureCode` milik app, bukan `ErrorCode` hasil generate**, agar `Failure` bisa dipakai domain tanpa mengimpor DTO (PRD: domain tidak mengimpor DTO). `failureCodeOf` memakai switch exhaustif tanpa `default`, jadi `ErrorCode` baru di kontrak memaksa pemetaan dan teks ditambahkan.
- **Teks kegagalan di `core/l10n/failure_messages.dart`**, tanpa ARB/`intl`: app satu bahasa. `flutter_localizations` dipasang agar teks bawaan Material berbahasa Indonesia.
- **`fieldIssueMessage` untuk kode issue Zod** (`required`, `too_small`, `too_big`, …) sudah disediakan untuk T-016 (error validasi di field judul).
- **`TokenProvider` sebagai port** agar interceptor diuji tanpa Firebase; refresh memakai `getIdToken(true)`. Request ulang lewat Dio yang sama (interceptor jalan lagi, membaca token yang baru di-refresh); penanda `extra['authRetried']` mencegah pengulangan kedua.
- **Gagal membaca token di `onRequest` → request ditolak sebagai `DioException`** (menjadi `Failure` `unknown` lewat `apiCall`), bukan dikirim tanpa token.
- **Dio sungguhan + `FakeHttpAdapter` di test**, bukan mock Dio, agar perilaku interceptor dan pemetaan respons diuji ujung ke ujung.
- **`DioExceptionType` lain (termasuk `transformTimeout`, `cancel`, `badCertificate`) → `unknown`** lewat `default`, agar tipe baru dio tidak memecah build.
- **`configureDependencies` menerima `FirebaseAuth` dan `GetIt` opsional** agar test DI tidak butuh `Firebase.initializeApp`.
- **Lint tambahan** (`strict-casts`, `strict-inference`, `strict-raw-types`, `always_use_package_imports`, `prefer_single_quotes`) dan `dart format` dengan lebar bawaan 80. Diusulkan tetap; sudah dicatat di `docs/conventions.md`.
- **Beranda sementara di `app_router.dart`**, diganti halaman fitur di T-014.
- Timeout Dio: connect 10 detik, receive 30 detik.

Usulan untuk `docs/conventions.md`: sudah ditambahkan (bagian "Flutter").
