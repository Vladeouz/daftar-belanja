## Keputusan yang diambil sendiri

- **Nama file ikut diganti** menjadi `scripts/prereq.mjs` (bukan hanya nama script), agar nama script dan file sama. Diusulkan masuk konvensi (sudah ditulis di `conventions.md`).
- **Format Biome:** spasi 2, lebar 100, kutip tunggal, titik koma selalu, LF; `organizeImports` aktif; `vcs.useIgnoreFile` agar mengikuti `.gitignore`.
- **`spawnSync(perintah, { shell: true })`** dengan string perintah (bukan array argumen), supaya `pnpm.cmd`/`flutter.bat` ditemukan di Windows tanpa peringatan DEP0190 Node 24.
- **Cek Flutter:** channel harus `stable` (dibaca dari `flutter --version --machine`); versi pastinya belum ditegakkan dan baru dicatat di T-004.
- **Cek Android SDK:** `ANDROID_HOME`/`ANDROID_SDK_ROOT`, lalu lokasi default per OS; hanya peringatan bila tidak ada SDK atau emulator.
- **`.gitignore`** sudah memuat pola Flutter (`.dart_tool/`, `build/`) dan `.claude/settings.local.json`. File itu di mesin ini hanya di-ignore lewat ignore global Git, sehingga Biome tidak tahu.
- **Script `lint`/`format`** ditambahkan sebagai alias `biome check`.
- **pnpm-workspace** memakai glob `apps/*` dan `packages/*`; `apps/app` (Flutter, tanpa `package.json`) otomatis diabaikan pnpm.

## Hasil spike (D-08 Biome)

Berhasil. Biome 2.5.14 terpasang sebagai satu binary per platform tanpa build script, berjalan di Windows sekitar 10 ms untuk 3 file, dan menangkap `noUnusedImports`, `noDoubleEquals`, `noDebugger`, serta pelanggaran format pada file uji sementara (sudah dihapus). Catatan: di 2.5, `linter.rules.recommended` sudah deprecated dan diganti `linter.rules.preset: "recommended"` (lewat `biome migrate`). **Rekomendasi: tetap D-08**, tidak perlu cadangan ESLint + Prettier.
