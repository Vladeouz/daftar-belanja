# T-003 Spike kontrak: Hono → `openapi.json` → client Dart swagger_parser

## Status

Selesai. Branch: `chore/t-003-spike-kontrak`.

## Ringkasan

Spike di `spikes/contract/` (sementara, dihapus di T-020):

- `api/`: package Node mandiri (di luar workspace pnpm, dipasang dengan `pnpm install --ignore-workspace`). `src/app.ts` berisi satu route `POST /v1/notes` dengan `@hono/zod-openapi`, skema error PRD bagian 5 (`ErrorCode` enum, `ApiError`, `ErrorIssue`, `ErrorBody`) dipakai di respons 401, 422, dan 500, serta `defaultHook` yang membentuk `details` sesuai bagian 5 (`required`, path titik, `_root`). `scripts/export.ts` menulis `openapi.json` (OpenAPI 3.1) dan dua contoh respons **nyata** dari `app.request()` (201 dan 422) ke `dart/test/fixtures/`, lalu memformatnya dengan Biome.
- `dart/`: package Dart murni `api_client` (tanpa Flutter). `swagger_parser.yaml` membaca `../openapi.json` dan menulis ke `lib/src/api/`; `build_runner` menghasilkan `.g.dart` (json_serializable + retrofit). `lib/api_client.dart` mengekspor semuanya.
- `dart/test/api_client_test.dart`: 6 test, men-deserialize fixture sukses dan error secara langsung, lewat `NotesClient` (retrofit + dio dengan adapter palsu), `ErrorCode` tak dikenal menjadi `$unknown`, dan daftar `ErrorCode` sama dengan PRD.

## Keputusan yang diambil sendiri

- **Spike di luar workspace pnpm** (`--ignore-workspace`), agar `pnpm-workspace.yaml` tidak diubah untuk kode sementara.
- **OpenAPI 3.1** (`getOpenAPI31Document`). swagger_parser menanganinya; nullable (`type: ["string","null"]`) menjadi `String?` (dicek dengan probe sekali pakai di scratchpad: `nextCursor`, `email` nullable, path param UUID, query `limit` default 20 dan `cursor` opsional; semua dihasilkan dengan benar).
- **Objek error dalam diberi nama komponen `ApiError`.** Tanpa nama, swagger_parser membuat kelas `Error` yang menutupi `Error` dari `dart:core`.
- **Fixture diambil dari respons nyata route**, bukan ditulis tangan, agar test Dart membuktikan kecocokan dua sisi.
- **Hasil export diformat dengan Biome.** `JSON.stringify(…, 2)` memecah array pendek per baris sehingga `pnpm biome check .` gagal; format ulang membuatnya bersih dan tetap deterministik.
- **Versi dipin di spike** (hono 4.13.11, @hono/zod-openapi 1.6.3, zod 4.6.5, typescript 7.0.2, tsx 4.23.15; swagger_parser 1.45.0, retrofit 4.10.0, retrofit_generator 10.2.11, dio 5.11.1, json_annotation 4.12.0, json_serializable 6.14.1, build_runner 2.16.1). Belum dicatat di `docs/conventions.md` karena spike sementara; dicatat saat dipasang sungguhan (T-005, T-012).

## Hasil spike

**Berhasil. Rekomendasi: tetap memakai D-02 (swagger_parser)**; cadangan openapi-generator tidak diperlukan.

Catatan untuk T-012 dan T-013:

1. `json_serializer: json_serializable` + retrofit cukup; freezed tidak perlu untuk DTO (entity domain tetap kelas sendiri dengan equatable).
2. `unknown_enum_value: true` (default) membuat `ErrorCode` baru dari server menjadi `$unknown`, bukan exception. Flutter memetakan `$unknown` ke teks umum (FR-11).
3. Beri nama komponen setiap objek Zod bersarang yang penting (`.openapi('Nama')`), agar nama kelas Dart terkendali.
4. File hasil generate berisi `ignore_for_file: type=lint` dan tidak rapi menurut `dart format`. `contract:check` sebaiknya membandingkan hasil generate apa adanya (sudah deterministik, LF), dan `dart format` tidak dijalankan pada `lib/src/` generate, atau dijalankan selalu sebagai bagian dari `contract:generate`. Pilih salah satu di T-012.
5. `build_runner` pertama kali ~40 detik; relevan untuk target waktu `pnpm check` (NFR-02) bila `contract:check` meng-generate ulang. Build ulang ~2,5 detik.
6. `openapi.json` perlu diformat Biome setelah export (atau dikecualikan dari Biome).
7. Error 422 sampai ke Flutter sebagai `DioException` dengan `response.data` berupa `Map`; interceptor/mapper di T-013 membaca `ErrorBody.fromJson` dari sana.

## Kendala

- **pnpm 12 gagal (exit 1) karena build script `esbuild` (dependency `tsx`) belum disetujui**: `ERR_PNPM_IGNORED_BUILDS`. Paket tetap terpasang dan `tsx` berjalan (binary esbuild datang dari paket platform), tetapi exit code 1 akan menggagalkan CI. Di T-005, `pnpm-workspace.yaml` perlu mengizinkan build `esbuild` (lewat `pnpm approve-builds` atau pengaturan setara), lalu dicatat di `docs/conventions.md`.
- Path gaya Git Bash (`/c/Users/...`) tidak dikenali `swagger_parser -f`; pakai path relatif atau gaya Windows. Tidak berpengaruh bila config memakai path relatif (seperti di spike).
