## Ringkasan

- **`scripts/init-project.mjs`** (`pnpm init-project <nama>`):
  - Validasi nama: huruf kecil, angka, dan tanda hubung, diawali huruf; maksimal 25 karakter (project ID Firebase maksimal 30, termasuk `demo-`); `template` ditolak.
  - Penanda sudah dijalankan: `docs/PRD.md` ada atau `.firebaserc` tidak lagi berisi `demo-template`. Run kedua ditolak (exit 1) sebelum ada file yang disentuh.
  - Penggantian di semua file teks yang dilacak Git (`git ls-files`), kecuali `docs/template-build/` (sejarah), `scripts/init-project.mjs`, dan `pnpm-lock.yaml`; file biner dilewati:
    - `demo-template` → `demo-<nama>` (termasuk bucket `demo-<nama>.appspot.com`).
    - Nama database `template` → `<nama>` dengan `-` menjadi `_` pada pola `POSTGRES_DB=`/`POSTGRES_DB:`/`${POSTGRES_DB:-…}`, `:5432/…`, `pg_isready … -d …` (ci.yml); `template_test` → `<nama>_test`.
  - Judul README (`# <nama>`) dan kalimat pembukanya; `name` di `package.json` root.
  - `docs/PRD.md` dan `docs/TASKS.md` diisi placeholder (struktur bagian sama dengan PRD/TASKS template, merujuk `docs/template-build/` sebagai contoh); `docs/logs/` dikosongkan dan diberi `.gitkeep`.
  - Setelah mengganti, script memeriksa tidak ada lagi `demo-template` di file yang dilacak; bila ada, gagal dengan daftar filenya.
  - Mencetak ringkasan dan langkah berikutnya (`.env` disalin ulang, `docker compose down -v` bila volume lama, `pnpm check`, isi PRD/TASKS).
- **`package.json`**: script `init-project`. Nama aman dari bentrok perintah bawaan (`pnpm help init-project` → `unrecognized subcommand`, D-14).
- **`README.md`**: bagian "Memulai proyek baru dari template" dan baris di tabel "Perintah".
